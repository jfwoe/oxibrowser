# OxiBrowser Agent Skills

Installable skill guides for AI agents. Each folder contains a `SKILL.md` with a
bounded, self-contained procedure an agent can follow without extra context.

| Skill | Purpose |
|---|---|
| [`oxibrowser-install`](oxibrowser-install/SKILL.md) | Detect platform and install the OxiBrowser CLI |
| [`oxibrowser-webfetch`](oxibrowser-webfetch/SKILL.md) | Fetch, extract, and interact with web pages via the CLI |

Programmatic equivalent: `oxibrowser skill` prints the ~150-token command guide.
